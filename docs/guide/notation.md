# 符号与约定

本书尽量让每个符号只承担一种含义。第一次出现时会给出定义，这里给一张总表。

## 频率与音高

| 符号 | 含义 | 单位 | 首次出现 |
| --- | --- | --- | --- |
| $f$ | 频率（frequency） | Hz | 第 0 章 |
| $T$ | 周期，$T = 1/f$ | s | 第 1 章 |
| $\omega$ | 角频率，$\omega = 2\pi f$ | rad/s | 第 1 章 |
| $a_n,b_n$ | 第 $n$ 次谐波的余弦、正弦系数 | — | 第 1 章 |
| $\varphi$ | 简谐振动的初相位 | rad | 第 1 章 |
| $f_0$ | 参考频率（本书默认 440 Hz） | Hz | 第 0 章 |
| $p$ | 音高坐标，$p = 1200\log_2(f/f_0)$ | cent（¢） | 第 0 章 |
| $\Delta p$ | 音程，两个音高坐标之差 | cent | 第 0 章 |
| $r$ | 频率比，$r = f_2/f_1$ | — | 第 0 章 |

## 写作约定

- **定义**：引入一个新名词，给出它的数学表达式与适用条件。
- **公设**（postulate）：无法从本书内部证明、依赖物理或生理事实的假设。
- **定理**：由定义与公设推出的结论，附带证明或证明思路。
- **可运行实验**：一段能在 3 秒内跑完、产出一个可检验数字的代码。
- 所有音程一律用 **cent**（1 个八度 = 1200 ¢），除非明说使用其他单位。
- 频率比写作 $m:n$，为两个整数时称为**整数比**（integer ratio）。
