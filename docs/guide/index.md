# 如何使用本书

> 这本书不要求你先成为音乐家，只要求你愿意把「听起来怎样」翻译成「算起来怎样」。

## 三条阅读路径

| 路径 | 适合的人 | 顺序 | 时长 |
| --- | --- | --- | --- |
| **快读**（3 天） | 只想搞懂「协和与律制」的程序员 | 0 → 1 → 2 → 3 → 4 → 5 | 每天 1~2 小时 |
| **精读**（6 周） | 想完整建立公理化直觉的理科生 | 0–9 全书 + 附录 A/B | 每天 1 小时 |
| **工程**（边做边学） | 要把结论做成工具的人 | 每章「可运行实验」全做，再回读正文 | 不限 |

三条路径都必须经过第 2 章。没有对数坐标，后面所有内容都会变成新的死记硬背。

## 每章的结构

每章都按同一套模板组织，方便你跳读：

1. **开场问题** —— 3 到 5 个「为什么」，本章结束时必须能回答；
2. **定义 / 公设** —— 引入新对象，写明它由什么量定义、适用边界在哪里；
3. **定理与推导** —— 从公设出发，给出可验证的结论，必要时附证明思路；
4. **可运行实验** —— 一个 Python 脚本，把公式变成终端里的数字；
5. **小结与习题** —— 用一段话收束，用一组习题检查是否真的懂了。

<Box kind="note" title="关于「定理」的诚实说明">

本书的「定理」都是由我们自己的模型推出的结论，不是自然定律。模型可以被证伪，这正是它比「乐理老师说」更好用的地方。凡是依赖听知觉实验数据的假设，都会标成**公设**（例如临界带宽的近似公式）。

</Box>

## 代码怎么跑

仓库根目录有一个 `code/` 文件夹，所有实验脚本只依赖 Python 标准库。克隆本书仓库或你自己的 fork 后，在仓库根目录执行：

```bash
python code/ch03_consonance.py      # 协和度曲线
python code/ch04_tuning.py          # 三种律制偏差表
python code/ch05_scale_search.py    # 从泛音列搜索最优音阶
```

脚本输出格式统一为「表格 + 一句话结论」，可以直接粘贴到笔记里。想把曲线画出来，可以照附录 B.4 的模板读数据，再用你手边的绘图工具画；本书自己的脚本不依赖任何绘图库。

## 本书的技术栈

这本书本身就是一台可复现的实验设备：

- **VitePress** 静态站点（Markdown + Vue 3），公式由 MathJax 渲染；
- **GitHub Actions** 自动构建，**GitHub Pages** 托管；
- **Python 3.12** 验证所有数值结论；
- 交互式演示是纯 Vue 组件，不依赖任何第三方图表库。

也就是说：你看到的每一条曲线、每一个数值，都能在仓库里找到生成它的代码。

</Box>
